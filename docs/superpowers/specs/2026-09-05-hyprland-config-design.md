# Hyprland desktop configuration via chezmoi — design

Date: 2026-09-05
Status: approved in brainstorming, awaiting implementation plan
Depends on: `2026-09-05-hyprland-image-design.md` (the bazzy image, now
booted and signed)

## Goal

Make the Hyprland session on this machine usable and good-looking: the
same shortcuts, workspaces and mouse-driven bar the xmonad + xmobar setup
had, with the layout set reduced to the three that were actually used, KDE
programs where the old config used others, and a richer "glass" look on
the old palette. Everything is managed by chezmoi in
`~/.local/share/chezmoi` and applied to `~/.config`.

## Context

- Host: bazzy image (Bazzite stable, Fedora 44), Hyprland 0.56.2,
  waybar 0.15.0, rofi 2.0.0 (Wayland native), dunst 1.13.2,
  hyprpaper 0.8.4. One display, HDMI-A-1, 2560x1440 at 1.25 scale.
- Hyprland 0.55 deprecated the hyprlang `hyprland.conf` format in favor
  of Lua. The autogenerated config on this machine is already
  `~/.config/hypr/hyprland.lua`. The full Lua API is documented locally in
  `/usr/share/hypr/stubs/hl.meta.lua`, which is the reference for
  implementation, not memory of the old format.
- The old configs live at `~/.xmonad/app/Main.hs`,
  `~/.home/config/xmobar/xmobarrc`, `~/.home/config/rofi/*.rasi` and
  `~/.home/config/dunst/dunstrc`. The `~/.config` symlinks for rofi, dunst
  and xmobar point into a Guix store that no longer exists.
- Keys are Colemak-positioned through kmonad (focus on `n`/`e`, resize on
  `h`/`l`); Hyprland sees a plain `us` layout. Key positions carry over
  unchanged.
- Sunshine is a Homebrew install at `/home/linuxbrew/.linuxbrew/bin`.
- Nothing packaged in the image plays a video wallpaper under Wayland.

## Decisions

| Decision | Choice | Why |
|---|---|---|
| Config format | Lua, split into modules | hyprlang is deprecated; Lua has event hooks and functions natively |
| Structure | Modular Lua + chezmoi-templated palette | One palette file restyles every app; the seam a theme engine plugs into |
| Tiling layout | Hyprland `master` | Closest to xmonad's tall; keeps focus/swap-master keys meaningful |
| "full" / "fullAlt" | Per-window fullscreen toggle | Native Hyprland behavior; no daemon. New windows open tiled |
| Terminal | kitty | Themeable from a plain file chezmoi can template |
| File manager | dolphin | KDE programs preferred |
| Look | "Glass" on the old palette | Familiar colors, translucent blurred bar, rounded, gradient borders |
| Wallpaper | hyprpaper, still image | mpvpaper is a later image change; the swap point is documented |
| Locking / idle | None | User turns the monitor off by hand. No hyprlock, no hypridle |
| Hydrus keys | Three keys, old Hob scripts | Kept as-is; they may fail until the Hob helpers are revived |
| Autostart | waybar, hyprpaper, dunst, polkit agent, applets, cliphist, emacs daemon, syncthing, sunshine | Steam stays out |

Alternatives rejected: a single Lua file with colors pasted per app (no
theme seam, five-file restyles); the deprecated `hyprland.conf` format
(more examples online, but being retired); wallpaper-driven colors via
matugen or wallust now (see "Theme seam" below, it is a later step).

## Files

All paths are chezmoi source paths under `~/.local/share/chezmoi`, with
their targets. `.tmpl` files read the palette from `.chezmoidata`.

| Source | Target | Purpose |
|---|---|---|
| `.chezmoidata/desktop.toml` | (data) | Palette, fonts, wallpaper path, monitor line |
| `dot_config/hypr/hyprland.lua` | `~/.config/hypr/hyprland.lua` | Entry point; requires the modules below in order |
| `dot_config/hypr/colors.lua.tmpl` | `hypr/colors.lua` | Palette as a Lua table, generated from the data file |
| `dot_config/hypr/apps.lua` | `hypr/apps.lua` | Program commands in one place (terminal, browsers, launchers…) |
| `dot_config/hypr/look.lua` | `hypr/look.lua` | monitor, general, decoration, animations, layer rules for blur |
| `dot_config/hypr/binds.lua` | `hypr/binds.lua` | Every keybind and mouse bind, plus the `super+a` and `super+s` submaps |
| `dot_config/hypr/rules.lua` | `hypr/rules.lua` | Workspace names, window rules (float, borderless, shift) |
| `dot_config/hypr/autostart.lua` | `hypr/autostart.lua` | `hl.exec_cmd` calls on the start event; env vars |
| `dot_config/hypr/hyprpaper.conf.tmpl` | `hypr/hyprpaper.conf` | Preload + wallpaper from the data file; mpvpaper note |
| `dot_config/waybar/config.jsonc` | `waybar/config.jsonc` | Modules and click actions |
| `dot_config/waybar/style.css.tmpl` | `waybar/style.css` | Glass styling from the palette |
| `dot_config/waybar/executable_keys.sh` | `waybar/keys.sh` | Renders the key table into rofi for `super+shift+/` |
| `dot_config/rofi/config.rasi` | `rofi/config.rasi` | modi, keybindings, icon settings |
| `dot_config/rofi/theme.rasi.tmpl` | `rofi/theme.rasi` | Centered blurred panel, old theme ported |
| `dot_config/dunst/dunstrc.tmpl` | `dunst/dunstrc` | Old dunstrc ported, palette templated |
| `dot_config/kitty/kitty.conf.tmpl` | `kitty/kitty.conf` | Font and palette |
| `README.md` | (source only) | New "Hyprland desktop" section: layout, keys, theme seam |

`chezmoi apply` replaces the dangling `~/.config/rofi/*.rasi`,
`~/.config/dunst/dunstrc` symlinks and the autogenerated
`~/.config/hypr/hyprland.lua`. chezmoi does not prompt for files it has
never written, so the plan removes the dead symlinks and moves the
autogenerated file to `hyprland.lua.orig` before the first apply.
`~/.config/xmobar` and `~/.xmonad` are left alone. `chezmoi verify` is the
success signal for the apply itself.

## Palette and theme seam

`.chezmoidata/desktop.toml`:

```toml
[desktop]
wallpaper = "/usr/share/hypr/wall2.png"   # placeholder until one is chosen
monitor   = "HDMI-A-1, 2560x1440@60, 0x0, 1.25"
font      = "Fira Code"
font_size = 12
icon_font = "Symbols Nerd Font"

[desktop.colors]
bg        = "#14191e"   # bar, rofi, dunst background
bg_alt    = "#0f1316"
fg        = "#e6e6e8"
border    = "#2c3034"
muted     = "#909aa2"
dim       = "#454459"   # inactive workspace dots, inactive border
teal      = "#42aa9e"   # selected, focused border start
cyan      = "#62d2db"   # active workspace, accents
violet    = "#8d74a7"   # focused border end
rose      = "#e55c7a"   # close button, urgent, critical
green     = "#31e183"   # window title
yellow    = "#f4c744"   # launcher glyph
glass_alpha = "cc"      # hex alpha applied to bg in translucent surfaces
```

Every templated file reads only from this table. Reviving the old
`themescheme` engine, or adopting matugen or wallust, later means one
thing: have the tool write this file (or a chezmoi `.chezmoidata` file it
owns), then `chezmoi apply`. No template needs to change. The README
records this and the fact that matugen is present in the Hyprland COPR if
it is ever wanted in the image.

## Hyprland

### Layout and look (`look.lua`)

- `general.layout = "master"`, `master.new_status = "slave"`, master takes
  55% by default (xmonad used 50%, but the wider ratio suits 2560 wide).
- Gaps 6 inner, 12 outer; border 2px; rounding 10; shadows on; blur
  enabled with size 6, passes 3, and `blur.popups = true` so rofi and
  dunst layers blur what is behind them. Layer rules add blur and
  `ignore_alpha` for the waybar, rofi and dunst namespaces.
- Active border: gradient teal → violet at 45°, animated by the `border`
  animation. Inactive border: `dim`.
- Animations: stock curves from the autogenerated file, with the
  workspace animation set to `slide` rather than `fade`.
- `misc.disable_hyprland_logo = true`, `force_default_wallpaper = 0`.
- Cursor: Breeze, size 24, via `hl.env` for `XCURSOR_THEME`,
  `XCURSOR_SIZE`, `HYPRCURSOR_SIZE`.
- Monitor line comes from the data file so a second display is a one-line
  change.

### Workspaces and rules (`rules.lua`)

Workspaces 1–9 get `default_name` chat, work1, work2, work3, work4, work5,
game, image, media. Window rules, ported from the xmonad manage hooks:

| Rule | Match | Effect |
|---|---|---|
| borderless | class `mpv`; title `^hydrus client media viewer` | `border_size = 0`, `rounding = 0` |
| float centers | class `Hydrus Client` except titles `^main` and the media viewer; class `^Gimp-` except the main window; class `Blender` except title `Blender`; class `Inkscape` except `.* - Inkscape$` | float |
| shift | class `discord` → chat; `steam`, `Lutris`, `PolyMC`, `polyrun` → game; `Hydrus Client` → image; `FreeTube` → media | move to workspace and follow |
| xwayland fix | empty class and title, xwayland, floating | `no_focus` |

Flatpak apps expose their app ids under Wayland (`com.discordapp.Discord`
and so on); the rules match on both the old X class and the flatpak id.
The implementer verifies the real class of each app with
`hyprctl clients` during the acceptance walk-through and adjusts.

### Keybinds (`binds.lua`)

Super is the modifier. Chords are submaps defined with
`hl.define_submap`; each submap resets after one key or on Escape.

| Group | Key | Dispatcher / command |
|---|---|---|
| Session | super+shift+r | `hyprctl reload` |
| | super+shift+s | `nwg-bar` |
| | super+shift+/ | `~/.config/waybar/keys.sh` (key table in rofi) |
| Launch | super+r | `rofi -show drun` |
| | super+w | `rofi -show window` |
| | super+Return | `kitty` |
| | super+ctrl+Delete | `kitty -e btop` |
| super+s chord | b | `flatpak run io.gitlab.librewolf-community` |
| | shift+b | `flatpak run com.brave.Browser` |
| | ctrl+b | `freetube` |
| | d | `dolphin` |
| | e | `emacsclient -c` |
| | m | `flatpak run org.kde.haruna` (no music player installed) |
| | g | `steam` |
| | p / shift+p / ctrl+p | `~/.home/bash/exec/hydrus.sh`, `hydrus-1.sh`, `hydrus-0.sh` |
| Windows | super+q, super+Backspace | `window.close` |
| | super+shift+q, super+shift+Backspace | close every window on the workspace (Lua loop over `hl.get_windows`) |
| | super+h / super+l | `window.resize` −40 / +40 on x |
| | super+alt+j / super+alt+k | `window.resize` −40 / +40 on y |
| | super+m | layout msg `focusmaster` |
| | super+shift+m | layout msg `swapwithmaster` |
| | super+n / super+e | `window.cycle_next` / prev |
| | super+shift+n / super+shift+e | `window.swap` next / prev |
| | super+shift+Tab / super+ctrl+Tab | layout msg `rollnext` / `rollprev` |
| Groups | super+ctrl+m | `group.toggle` |
| | super+ctrl+u | `group.move_window` out (ungroup) |
| | super+ctrl+. / super+ctrl+, | `group.next` / `group.prev` |
| super+a chord | t | `fullscreen_state` 0 (tiled) |
| | f | `fullscreen_state` 1 (maximized, bar visible) |
| | shift+f | `fullscreen_state` 2 (true fullscreen) |
| Toggles | super+ctrl+Space | `pkill -SIGUSR1 waybar` (hide/show bar) |
| | super+shift+Space | toggle `general.border_size` 0/2 via Lua |
| | super+f | `window.float` toggle |
| Workspaces | super+1..9 | `focus` workspace n |
| | super+shift+1..9 | `window.move` to workspace n |
| | super+shift+KP_Add / KP_Subtract | move window to next / prev workspace and follow |
| Wallpaper | super+v / super+shift+v | placeholders that call `hyprctl hyprpaper` to reload; the README marks where mpvpaper goes |
| Screenshot | Print | `grim -g "$(slurp)" - \| tee ~/Pictures/$(date …).png \| wl-copy` |
| Mouse | super+LMB drag / RMB drag | `window.drag` / `window.resize` |
| | super+scroll up / down | workspace e+1 / e−1 |
| Media keys | XF86Audio* | `wpctl` volume and `playerctl`, locked and repeating |

Dropped from the xmonad set: alt-key spacing adjustments, monitor switch
keys, the compositor toggle, `super+a b`, all other layouts, hyprlock.

### Autostart (`autostart.lua`)

On the `hyprland.start` event: `waybar`, `hyprpaper`, `dunst`,
`hyprpolkitagent`, `nm-applet`, `blueman-applet`,
`wl-paste --watch cliphist store`, `emacs --daemon`,
`syncthing --no-browser`, `sunshine`. Steam is not started.

Environment: `XDG_CURRENT_DESKTOP=Hyprland`, `XDG_SESSION_DESKTOP=Hyprland`,
`QT_QPA_PLATFORM=wayland`, `QT_QPA_PLATFORMTHEME=kde`, `MOZ_ENABLE_WAYLAND=1`,
cursor variables above. The Hyprland portal handles screenshots and
screencast; the KDE portal handles file choosers, via an
`xdg-desktop-portal` `portals.conf` only if the package defaults do not
already do this (checked during implementation, not assumed).

## Waybar

Single top bar, `layer = top`, 34px high, 8px margin on top and sides so
it floats, translucent `bg` with `glass_alpha` behind a Hyprland blur
layer rule. Modules are rounded pills with 6px spacing.

Left: `custom/launcher` (left click drun, right click window),
`hyprland/workspaces` (persistent 1–9, `format-icons` for active
`●`, has-windows `◎`, empty `○`; on-click `activate`; scroll cycles),
`hyprland/submap` (shows `a` or `s` while a chord is pending, hidden
otherwise), `custom/close`, `custom/prev`, `custom/next` (each runs
`hyprctl dispatch …`), `hyprland/window` (60 chars, `.empty` hides it).

Center: `clock`, format `%a %-m/%-d %-I:%M %p`, calendar tooltip.

Right: `pulseaudio` (scroll adjusts, click mutes, right click
`pavucontrol`), `network`, `bluetooth`, `tray`, `custom/power`
(`nwg-bar`).

Colors: active workspace `cyan` with a soft glow, workspaces with windows
`teal`, empty `dim`, title `green`, close `rose`, prev/next `cyan`,
launcher `yellow`, separators `muted`, all from the palette template.

## rofi, dunst, kitty

- rofi: `modi = "drun,window"`, icons on, centered panel 800px wide with
  8 rows, rounded 12px, `bg` at `glass_alpha` so Hyprland's blur shows
  through, the old selection colors (`teal` selected, `cyan` active,
  `rose` urgent, `violet` selected-active) kept. Default keys.
- dunst: old file ported; `offset` moved to sit under the floating bar;
  `corner_radius = 10`; `transparency` on with the same alpha; icons left.
- kitty: `Fira Code` 12, palette mapped onto the 16 terminal colors with
  `bg` background and `background_opacity 0.9`.

## Verification

Before apply: `chezmoi diff` lists only the files in the table above.
`chezmoi apply -v` then `chezmoi verify` exits 0.

Inside a Hyprland session, the user runs the checklist the plan produces:

1. `hyprctl configerrors` prints nothing; `super+shift+r` reloads cleanly.
2. Each row of the key table, in order, does what it says.
3. Each bar click and scroll target does what it says.
4. Open mpv, Discord, Steam, hydrus: placement and borders match the rules.
5. Blur is visible behind the bar and rofi; the focused border animates.
6. `super+a f` keeps the bar visible; `super+a shift+f` covers it;
   `super+a t` returns to tiling.
7. Log back into Plasma; nothing there has changed.

Anything that fails is fixed and re-applied; the checklist is re-run from
the failing item.

## Out of scope

- mpvpaper / video wallpaper (image change first).
- Reviving `themescheme`, or adding matugen or wallust.
- Any change to the bazzy image, KDE, SDDM or kmonad.
- The Hob NFS helper scripts that the hydrus keys call.
- Locking and idle management.
